# Облегчённая сборка и выбор компонентов

**Готовый запуск без Qwen:** builds/Barni-Lite/ShinriTrialLauncher.exe. Переносимая версия — releases/ShinriTrialLauncher-Lite.zip: распакуйте целиком в новую папку. Python для запуска не нужен; Windows 10/11 и .NET Framework 4.8.

Без Qwen остаются каталог серверов, онлайн/пинг/игроки, избранное, Steam, Discord RPC, друзья Steam, сценарная Барни, её положение, озвучка Kseniya, узнавание персонажей по эталонам, колёса действий, инвентарь, распознавание речи, команды памяти и справочник правил. Свободных ответов модели, описания изображения Qwen3-VL и фонового полноценного зрения нет. Сценарные реакции не заменяют свободный разговор. Узнавание использует небольшой DINOv2, а распознавание речи — Vosk; они включены и не являются Qwen.

Лаунчер проверяет наличие компонентов. При отсутствии Qwen её функции отключены, настройки генерации скрыты. Предпочтения полной версии в LocalAppData не сбрасываются: если вернуть компонент, они снова действуют. Без Kseniya используется доступный голос Windows; виртуальная передача в игру требует компонента voice. Без vision не запускается экранная помощница и анализ, но серверы, друзья, заметки и справочник доступны.

## Установщик

Распакуйте releases/ShinriTrialLauncher-Setup-Lite.zip и запустите Setup.exe. Все файлы архива должны лежать рядом: components.json и три ZIP-пакета. Установщик не скачивает файлы из интернета и не требует администратора при установке в стандартную пользовательскую папку. Выберите:

- Базовый лаунчер и справочник — обязательный компонент.
- vision — экранная Барни, узнавание, инвентарь и русское распознавание речи.
- voice — Kseniya и передача её голоса в игру. Без него можно использовать голос Windows.
- Qwen — свободный диалог и полноценное зрение; по умолчанию выключен.

Для выбора Qwen положите **releases/installer/Shinri-Qwen.zip** рядом с Setup.exe **до запуска установщика**. Этот большой пакет распространяется отдельно, поэтому скачивать его для Lite не нужно. Установщик показывает размер компонентов после распаковки и проверяет SHA256 архивов перед установкой. Последний флажок запуска лаунчера по умолчанию выключен.

Для настоящей Lite используйте новую папку. Установка с меньшим набором поверх полной версии не удаляет старые модели. Ненужные ранее установленные компоненты автоматически не стираются; личные настройки и заметки не удаляются. Установщик распаковывает выбранные компоненты в папку, не регистрирует деинсталлятор и не создаёт ярлыки. Лаунчер запускается через ShinriTrialLauncher.exe в выбранной папке. При отмене уже установленные файлы остаются; установку можно повторить.

## Сборка

1. ./build.ps1 -Test -OutputDirectory ./builds/Barni-Lite
2. Собрать tools/installer/Setup.cs компилятором .NET Framework 4.8 с System.Windows.Forms, System.Drawing, System.IO.Compression, System.IO.Compression.FileSystem, System.Web.Extensions в releases/installer/Setup.exe.
3. vision/.venv/Scripts/python.exe tools/package_lite.py — создать переносимую Lite, пакеты компонентов и архив установщика из полной builds/Barni-Continuous. Исходная полная сборка не меняется.

ZIP API: https://learn.microsoft.com/en-us/dotnet/api/system.io.compression.ziparchiveentry?view=netframework-4.8.1 .
